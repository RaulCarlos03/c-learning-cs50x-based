# CS50x Exercises

Personal collection of exercises and projects completed during my self-study of C with CS50x (2026) and additional practice exercises.

## About this repo

This repository contains my solutions to CS50x problem sets and additional exercises I designed or adapted while learning C. The code is written for learning purposes and reflects my progression through the course.

I worked through these exercises with the help of a tutoring LLM (Claude) for debugging guidance, conceptual explanations, and code review, while writing every line of code myself.

## Structure

- `week1/`: C basics — loops, conditionals, command-line arguments.
- `week2/`: Arrays, strings, ASCII manipulation, classic ciphers.
- `week3/`: Algorithms — searching, sorting, recursion.
- `extra/`: Additional exercises beyond CS50.

## How to compile and run

Each exercise can be compiled using either `make` (CS50 environment) or `gcc` directly. For example:

\`\`\`bash
gcc -o polybius polybius.c -lcs50
./polybius ABCDEFGHIKLMNOPQRSTUVWXYZ
\`\`\`

Note: The CS50 library is required for programs using `get_string`, `get_int`, etc. Available at https://cs50.readthedocs.io/libraries/cs50/c/
